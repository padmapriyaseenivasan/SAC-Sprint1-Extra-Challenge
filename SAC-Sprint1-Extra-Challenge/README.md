# SAC Sprint 1 Extra Challenge

## Features implemented
1. Multi-column responsive grid.
2. Number of columns can be changed using a number input or + / - buttons.
3. Columns can be reordered by entering an order number.
4. Columns can also be reordered with drag and drop.
5. Each column has an Edit button.
6. Edit dialog changes the title and background-color CSS property.
7. Users can type a HEX colour or choose from a colour picker/presets.

## Run
Open `index.html` in Chrome/Edge. No server or external dependency is required.

## Rubric mapping
- Metric 1: Multi-column grid
- Metric 2: Column count controls
- Metric 3: Numeric ordering + drag/drop
- Metric 4: Edit title + background colour
